# EXIF Overlay

**EXIF Overlay** is a privacy first tool that turns your camera settings into clean, fully customisable overlays for your photos.

Upload images, automatically read EXIF data (such as shutter speed, aperture, ISO, focal length, and camera model), and overlay that information directly onto the image, perfect for sharing on social media, portfolios, or behind-the-scenes posts.

The tool works both **online** and as a **desktop/mobile app** (Coming Soon), with full control over layout and styling.

---

## Features

- Upload up to **30 images at once**
- Automatically reads embedded EXIF data
- Clean, professional overlay output
- Fully customisable:
  - Enable or disable individual fields
  - Edit values manually (even if no EXIF data is present)
  - Change fonts and accent colours
  - Adjust background colour and blur strength
  - Scale and reposition overlays freely and more!
- What you see is exactly what gets exported

---

## No EXIF? No problem

If an image has missing or no EXIF data, all fields remain fully editable.  
EXIF Overlay is designed to work whether your metadata is complete, partial, or absent.

---

## Privacy-first by design

Your images stay on your device.

- No images are uploaded
- No EXIF data is sent to any server
- No personal information is collected

The only data collected is **anonymous usage statistics** (such as visit or app-open counts) to understand overall usage and improve the tool. This data cannot be used to identify users.
